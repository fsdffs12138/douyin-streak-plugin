# 验证说明

版本：1.2.0。最近验证日期：2026-10-21。

## 已完成

- 类型检查、构建及 76 项自动化测试通过。
- 模拟测试覆盖：北京时间日期切换、补发窗口、每日防重复、发送许可、页面刷新失效、草稿保护、账号校验、会话身份、群聊成员人数后缀、类型隔离、配置保存及只检查不发送。
- 虚拟列表测试覆盖：超过 100 屏、延迟分页、重绘等待、真正索引缺口、取消、超时、原位置恢复，以及不可选条目与正常条目混合。
- Chrome 本地模拟界面：三页共 180 个虚构会话，144 个好友、36 个群聊全部成为可选项；恢复初始滚动位置，没有切换其他聊天；可勾选群聊。
- 真实页面只读核对：个人与群聊列表、顶部名称和头像、本人消息结构、原生输入框及表情入口。打开群聊原生面板可见 23 个贴纸，包括“续火花”，随后关闭；没有点击表情项。
- 1.1.1 曾在手动打开目标个人会话后通过“只检查”，未发送消息。
