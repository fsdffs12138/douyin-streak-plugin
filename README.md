# 抖音续火插件

在抖音网页版聊天窗口内，选择好友或群聊，读取原生表情，并按北京时间安排每日发送。

当前版本：**1.2.0** · Chrome Manifest V3 · TypeScript · 本机保存配置

> 电脑必须开机且不休眠，Chrome 和已登录的抖音聊天页必须保持打开。当前版本不提供云端执行，也不能保证消息送达或火花续期成功。

[下载安装包](https://github.com/fsdffs12138/douyin-streak-plugin/releases/latest) · [更新记录](CHANGELOG.md) · [验证范围](docs/TESTING.md)

## 功能

| 功能 | 说明 |
| --- | --- |
| 聊天页内面板 | 拖动、缩放、收起；无需一直打开独立配置页 |
| 一键读取会话 | 自动滚动虚拟列表、等待分页、去重并恢复原位置；可中途停止 |
| 好友与群聊 | 按名称或类型筛选、勾选；确认界面和记录明确标注群聊 |
| 原生表情 | 支持网页可读取的普通小表情、贴纸和收藏表情；插件内选择只预览 |
| 每日计划 | 使用北京时间，支持当天补发窗口和发送间隔 |
| 只检查 | 核对第一个已保存对象及所选表情，不申请发送许可、不点击表情项 |
| 暂停与记录 | 暂停后续任务；记录结果不明时停止自动执行，避免盲目重试 |

## 安装

### 使用发布包

1. 在 [Releases](https://github.com/fsdffs12138/douyin-streak-plugin/releases) 下载 **`douyin-streak-v1.2.0.zip`** 并解压到固定目录。不要选择 GitHub 自动生成的 `Source code`，源码包需要自行构建。
2. 停用其他续火扩展或油猴脚本，避免多套任务同时运行。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后的 **`dist` 文件夹**，不要选择 ZIP 或项目根目录。
5. 打开或刷新 [抖音聊天页](https://www.douyin.com/chat)，确认出现「续火助手」面板。

要求：Chrome 120 或以上；已登录并能使用抖音网页版聊天。安装包不包含账号、会话名单或个人配置。

### 升级已有安装

先保存尚未保存的选择，将新版 `dist` 文件覆盖到原来加载的位置，在扩展管理页点击「重新加载」，再刷新抖音。无需卸载，原有好友选择和执行记录保留。重新连接后，定时发送需手动开启并保存。

## 使用

1. **读取会话**：点击「一键读取全部会话」，等待扫描结束。读取名单无需先连接，也不会逐个打开聊天正文。
2. **选择对象**：按名称筛选，或选择「仅好友 / 仅群聊」，勾选需要发送的对象。最多选择 100 个会话，读取数量不受此限制。
3. **准备会话**：打开一个已有本人历史消息和头像的聊天，点击「读取表情」，在插件面板内选择表情。
4. **连接并保存**：点击「连接当前会话」，设置时间、补发窗口并保存。默认关闭自动发送。
5. **先检查**：点击「只检查，不发送」。它只检查第一个已保存对象，成功不代表其他对象或实际发送已验证。
6. **启用发送**：需要定时执行时，勾选「启用每日定时发送」并保存；需要立即执行时，点击「立即发送」并核对对象、表情后确认。

发送时不要手动切换会话或修改输入框。「暂停全部」会停止后续队列和定时调度，不能撤回已经触发的消息。

### 群聊

- 群聊与好友共用选择、计划和表情流程；群名旁显示 `[群聊]`。
- 同时核对列表和聊天顶部的群名、群头像、会话类型，兼容群名后附带的成员人数。
- 目标群必须有当前可见的本人历史消息和头像，用于核对账号；缺少时停止，不用其他成员的头像代替。
- 群名或头像更改后需重新读取并选择。多个同名同头像的群无法可靠区分，不能替代平台群 ID 级别的身份识别。
- 输入框不可用、已有草稿或表情无法定位时停止执行。手机端独有表情不在支持范围内。

## 定时运行条件

| 场景 | 行为 |
| --- | --- |
| 电脑开机、Chrome 和聊天页打开、账号有效且已绑定 | 按已保存的启用状态检查每日计划 |
| 关机、休眠、浏览器关闭、离线或登录失效 | 无法发送 |
| 恢复运行 | 仅处理当天仍在补发窗口内的任务，不补发往日任务 |
| 页面刷新、导航或浏览器重启 | 需要重新连接；连接会关闭定时发送，须重新启用并保存 |
| 消息是否发出无法确认 | 停止自动任务，保留记录供人工核查，不自动重试 |

默认计划为北京时间 09:00、补发窗口 180 分钟、最小间隔 15 秒；后台约每 30 秒检查一次，不能保证精确准点。补发窗口支持 0–720 分钟；独立配置页可设置 10–300 秒的发送间隔。

本插件没有电脑开机、自动登录、云端托管或系统定时打开浏览器功能。外部定时工具打开网页后，仍需满足以上条件。

## 防重复与结果含义

同一账号特征、会话特征和北京时间日期只保留一次执行机会。更换表情不解除当天限制；头像或名称变化会形成新的身份特征，应先核查当天记录。

| 状态 | 含义 |
| --- | --- |
| 执行中 | 正在核对或操作页面 |
| 网页已出现 | 观察到新增且匹配的本人表情消息；不等于服务器送达、对方已读或续火成功 |
| 发送前停止 | 尚未点击表情发送路径，因身份、草稿或定位等问题停止 |
| 待核查 | 可能已发送但无法确认；停止自动任务，等待人工核查 |
| 人工确认 / 今日跳过 | 用户已自行核实，或选择当天不再执行 |

「发送前停止」也不自动重试。没有清空记录后重发入口，也不能判断当天是否已经由用户或其他插件发送。普通小表情在中断后可能留在输入框中，需要人工处理，插件不会擅自删除草稿。

## 常见问题

**读取显示“部分读取”？**

保持聊天页可见，等待页面加载后重试。扫描最长 3 分钟；取消、超时或真正的列表索引缺口会保留部分结果。网页没有提供总数量，因此不能保证读取隐藏、折叠分组或网页版未提供的会话。

**群聊或好友没有出现在可选名单？**

展开「不可选条目」查看原因。名称或头像未加载、图片来源不支持、同名同头像无法区分时，不会作为正常对象加入名单。

**“无法确认账号”或身份不一致？**

打开有本人历史消息和头像的会话后重新连接；核对目标名称和头像是否改变。账号校验基于本人头像资源路径，不是账号 ID，不能可靠区分共用同一头像的账号；任务期间不要切换账号。

**扩展没有响应、连接失效或面板没出现？**

确认加载的是 `dist`，重新加载扩展并刷新 `https://www.douyin.com/chat`；检查旧续火扩展是否停用。网页结构发生变化时可能需要更新适配代码。

## 隐私与权限

- 仅申请 `storage`、`alarms` 和抖音站点访问权限。
- 无业务服务器、遥测、远程脚本、模型调用或私有接口调用；不读取密码、Cookie 或浏览器账号数据库。
- 配置、选定对象和执行记录保存在扩展本地存储，记录保留约 45 天，日志最多 300 条。
- 头像与表情预览可能从抖音使用的 CDN 加载；群头像的可信 HTTP 链接转换为 HTTPS 用于预览。
- 仅检查页面当前显示的消息来核对结果，不持久化聊天正文。导出的记录包含会话名称，应自行保管。

## 开发

安装 Node.js 22 或兼容的更新版本后，在项目目录运行：

```sh
npm ci
npm run check
npm test
npm run build
```

输出的 `dist` 可直接作为解压扩展加载，无需 API Key。源码仓库不提交依赖目录和构建产物；已构建安装包放在 Releases。

```text
src/
  adapter.ts       抖音 DOM、身份核对、会话导航与原生表情定位
  scanner.ts       虚拟列表滚动、分页等待、去重与取消恢复
  content.ts       页面连接、发送前检查和单次发送流程
  background.ts    定时队列、发送许可、记录与恢复
  floating.ts/css  聊天页内面板
  options.ts       独立配置与记录界面
  model.ts         配置校验、身份标识和北京时间规则
public/            扩展清单与静态配置页
scripts/           构建及本地预览
tests/             自动化测试与虚构会话样例
```

本地模拟界面：`node scripts/qa-floating.mjs`，随后访问 `http://127.0.0.1:4319`。只使用虚构会话、不具备发送能力，也不会打包进扩展。
